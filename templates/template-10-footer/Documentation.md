# Template 10 - Footer

## Purpose

This template closes the portfolio with a minimal, high-trust brand finish.

## Branding Rationale

- Keeps the last impression clean and premium.
- Reinforces the brand name, signature, and navigation one final time.
- Leaves the visitor with a calm, polished ending.

## Design Decisions

- Compact three-column composition with clear brand, nav, and social zones.
- Uses the same dark glass surface language as the rest of the system.
- Includes a subtle signature line so the footer still feels human.

## Animation Philosophy

- The footer should appear with the same refined motion language as the rest of the site.
- No loud transitions or distracting motion.

## Reusability Strategy

- Works as a global footer for a personal site, startup landing page, or case-study collection.
- Navigation and social links are data-driven.

## Recommended Usage

- Place at the very end of the page.
- Keep the final copy short and brand-consistent.
