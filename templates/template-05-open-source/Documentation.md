# Template 05 - Open Source

## Purpose

This template reframes GitHub activity as brand evidence. It is meant to signal collaboration, documentation quality, and ecosystem value.

## Branding Rationale

- Open-source presence strengthens recruiter trust.
- Repo quality supports the idea of a serious engineering practice.
- Contributions and documentation help the developer brand feel durable.

## Design Decisions

- Uses stats, contribution blocks, and repo concepts to tell a layered story.
- Keeps the section lighter than the project section to avoid visual repetition.
- Surfaces ecosystem language like docs, PRs, and reusable packages.

## Animation Philosophy

- Cards should reveal gently to preserve the credibility of the section.
- Motion should make the section feel alive, not playful.

## Reusability Strategy

- Works for GitHub summaries, contributor profiles, or public tool libraries.
- All content is data-driven and easy to swap for live metrics later.

## Recommended Usage

- Place after projects or before AI focus.
- Use it to support a more mature engineering narrative.
- Pair with actual repos, pinned projects, or contribution proof when available.
